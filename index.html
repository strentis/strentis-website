01 / Control what an agent can do

Let it do the work.
Keep it in check.

Agent Immune

Imagine asking Claude Code to fix a bug in ./backend. Agent Immune lets it modify files there while blocking writes elsewhere.

Or suppose an agent reads a confidential customer file. You can label it as sensitive and restrict which services can receive its data, even if the agent copies it or produces a new report from it.

These restrictions are enforced at the system level, so agents cannot simply ignore them.

03 / Your approval

You have the final say

If an agent needs more access, it can request permission. Its limits won't change unless you approve the request.

Keep your credentials private

Let agents use services like GitHub without giving them your API keys or access tokens. Agent Immune handles authentication for approved operations.

Control its internet access

Agents can connect to the AI services they need to operate. Connections to other websites and online services are blocked unless you approve them.

Stop a misbehaving agent. Keep the others working.

If an agent misbehaves, you can shut it down along with every process it launched. Other agents can continue their work uninterrupted.

02 / Systematically check what an agent accomplished

“Done” should come with evidence.

Agent Contract

Before you give an agent a task, define what success looks like. What must it deliver? When is it due? Which requirements must it meet?

Imagine asking an agent to prepare a sales report. You can require specific figures, a balanced table, and set a deadline.

Agent Contract checks the agent's work against the requirements you set. No more sloppy work.

Install locally, define a write scope, and launch your agent through agent-immune.

# Register your project
$ agent-immune init .

# Let Claude work in the backend directory
$ agent-immune run --session backend --write ./backend -- claude

# Or run Codex in the frontend directory
$ agent-immune run --session frontend --write ./frontend -- codex

A few practical questions

What should I know before trying it?

Do I need to switch from Claude Code or Codex?

No. Keep using the coding agents you already know. Agent Immune controls what they can do, while Agent Contract checks whether their work meets your requirements.

Does agent-immune prevent every bad outcome?

No. Agent Immune enforces the limits you set, but agents can still make mistakes within those limits. Data they can read may also reach their AI provider or other services you've approved.

How does Agent Contract check the quality of an agent's work?

It can check requirements you define. It runs your tests and reports what passed or failed.

Can agents pay each other today?

Not yet. Our current products focus on controlling what agents can do and verifying their work. Payments, insurance, credit scores, and other elements of an economy for AI agents are part of our vision for the future.

Where can I read the technical details?

The documentation covers installation, approvals, network access, labelled data, verification, limitations, and release history. Both products are in private alpha.
