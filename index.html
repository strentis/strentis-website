The shift already happened

Agents don't just answer questions anymore. They write code, hold credentials, and act while you're not looking.

That's a feature! It's why autonomous AI is useful at all. But every extra bit of autonomy you grant an agent is also an extra bit of blast radius the moment that agent is compromised, confused, or simply wrong. Most tooling today asks you to choose between a leash so short the agent is useless, or trust so wide a single bad session can touch everything it can reach.

1 session

is usually all it takes for a mis-scoped agent to touch files, keys, or systems far outside the task it was actually given.

0 blast radius

is what a properly contained agent leaves behind, even when it's compromised, because containment was enforced by the kernel, not by the agent's own good behavior.

Our first product

An immune system for agentic software.

Maximum autonomy inside granted authority. Surgical branch containment the moment authority goes bad. Nothing else.

agent-immune
Runs Claude Code, Codex, or any coding agent inside a kernel-enforced authority boundary. With human-in-the-loop approval for anything outside a session's granted scope. 
# give an agent a narrow, real authority ceiling
$ agent-immune init .
$ agent-immune run --session backend --write ./backend -- claude

# it asks, you decide
$ agent-immune pending
$ agent-immune approve <id>

# the moment a session's authority goes bad
$ agent-immune quarantine backend
→ that session, and every descendant, stopped instantly.
→ every other session keeps working, untouched.

How it works

Containment enforced by the kernel, not by convention.

01

Authority ceiling

Every session starts with an explicit, human-set boundary on what the agent can read, write, and execute. It is enforced by Landlock and a bubblewrap ambient-authority mask, not by a configuration an agent can simply talk its way around.

02

Human-in-the-loop, only when needed

An agent can request more authority than it currently has. Nothing widens until a human explicitly approves it. Only agents launched after that approval inherit the new authority. An agent that is already running never gains it.

03

One command to quarantine

The moment a session's authority looks compromised, one command stops that entire branch, descendants, pending requests, and unconsumed grants, while every unrelated session keeps running.

04

Artifact-bound trust

A file a low-authority session produced doesn't silently inherit a higher-authority session's power just because that session later reads or runs it. Trust is requested, human-approved, and bound to the artifact's exact content.

05

Fails closed

If the mandatory protections can't actually be verified on your machine, kernel support, sandboxing, trusted state, the tool refuses to launch an unprotected session. No silent downgrade.

06

No new infrastructure

No daemon, no cloud service, no accounts. One local binary, installed once, running underneath the coding agents you already use.
